The regret theorem says that a learner can perform almost as well as its best fixed choice. We will use that fact to prove minimax: in a finite zero-sum game, randomization makes two apparently different orders of optimization agree. Applying the theorem to algorithms and inputs then gives a method for proving randomized lower bounds.

Games as loss matrices

A finite zero-sum game has two players with opposite objectives. We will call them the row player and the column player. The row player wants a small loss; the column player wants that same loss to be large. A matrix \(A\in[0,1]^{N\times m}\) specifies the loss \(A_{ij}\) when row \(i\) meets column \(j\).

A pure strategy chooses one row or column. A mixed strategy is a probability distribution over those choices. Write

\[ \Delta_N=\{p\in\mathbb R^N:p_i\ge0,\ \sum_i p_i=1\} \]

for the possible row distributions, and similarly use \(\Delta_m\) for columns. If the players independently sample from \(p\) and \(q\), their expected loss is

\[ p^{\mathsf T}Aq=\sum_{i=1}^N\sum_{j=1}^m p_iq_j A_{ij}. \]

The superscript \(\mathsf T\) denotes transpose; the expression is just an expected value, written as a matrix product. Let \(e_i\) denote a distribution concentrated on a single strategy. For example, \(p^{\mathsf T}Ae_j\) is the expected loss against column \(j\).

A game where randomization matters

Consider the loss matrix

\[ A=\begin{pmatrix}0&1\\1&0\end{pmatrix}. \]

If the row player commits to either pure row, the column player can choose a column giving loss 1. If the row player instead uses \(p=(1/2,1/2)\), either column gives expected loss \(1/2\). Conversely, the uniform column distribution makes every row incur loss \(1/2\). These two observations establish the value \(1/2\).

For this statement, the opponent can know the distribution but cannot observe the current sampled row before choosing its column. Seeing a distribution and seeing its realized random choice are different kinds of information.

The minimax theorem

There are two natural ways to ask how difficult a game is for the row player. First, choose a row distribution that works against the worst column. This gives the upper value

\[ U=\min_{p\in\Delta_N}\max_{q\in\Delta_m}p^{\mathsf T}Aq =\min_{p\in\Delta_N}\max_j p^{\mathsf T}Ae_j. \]

The second equality holds because averaging column losses cannot exceed the largest one. A column attaining that largest loss is already a best response.

Alternatively, fix a column distribution and allow the row player to respond optimally. The column player chooses the distribution making that response as costly as possible. This gives the lower value

\[ L=\max_{q\in\Delta_m}\min_{p\in\Delta_N}p^{\mathsf T}Aq =\max_{q\in\Delta_m}\min_i e_i^{\mathsf T}Aq. \]

Again, a pure strategy suffices for the inner optimization. These expressions represent different orders of commitment, so equality is not automatic. For pure strategies in the example above, the corresponding min–max is 1 while the max–min is 0.

Finite minimax theorem

For every finite loss matrix \(A\), allowing mixed strategies gives

\[ \min_{p\in\Delta_N}\max_{q\in\Delta_m}p^{\mathsf T}Aq = \max_{q\in\Delta_m}\min_{p\in\Delta_N}p^{\mathsf T}Aq. \]

The common number is the value of the game. Both players have distributions attaining their respective optima.

Thus there is a row distribution with loss at most the value against every column, and a column distribution forcing loss at least the value against every row. We will prove the equality using the regret bound from Part 1.

This proof follows the online-learning route in Cornell’s multiplicative-weights notes, Section 6.

Proof from the regret bound

The column player repeatedly attacks the learner’s current distribution. If the two game values had a fixed positive gap, those attacks would make the learner lose linearly more than some fixed row. The regret bound rules this out. Averaging will turn the sequence of play into one mixed strategy for each player.

The easy inequality

For any distributions \(p,q\), averaging the row losses and then the column losses gives

\[ \min_i e_i^{\mathsf T}Aq \le p^{\mathsf T}Aq \le \max_j p^{\mathsf T}Ae_j. \]

For every fixed \(p\), the left side is therefore at most the right side for all \(q\). Maximize the left side over \(q\), then minimize the right side over \(p\). This proves \(L\le U\). This inequality does not need an online-learning algorithm.

Play the game repeatedly

To get the reverse inequality, regard each row as an expert. Choose a horizon \(T\) and run exponential weights over these \(N\) rows with the horizon-tuned learning rate. After it announces its distribution \(p_t\), choose a best-response column

\[ j_t\in\operatorname*{arg\,max}_{1\le j\le m}p_t^{\mathsf T}Ae_j. \]

Use a fixed tie rule if several columns maximize the loss. Reveal to the learner the loss vector \(\ell_{i,t}=A_{i,j_t}\). These losses lie in \([0,1]\), so the regret theorem applies. The best response is allowed to depend on \(p_t\): the proof in Part 1 was valid even for such a choice.

The learner’s round loss is \(p_t^{\mathsf T}Ae_{j_t}\). Its best fixed expert is the best row against the whole sequence of selected columns. Hence

\[ \sum_{t=1}^T p_t^{\mathsf T}Ae_{j_t} \le \min_i\sum_{t=1}^T A_{i,j_t}+B_T, \qquad B_T=\sqrt{\frac{T\ln N}{2}}. \]

The game with one row is immediate, so we can assume \(N\ge2\) when using this bound.

Average the strategies

Define the average row distribution and the empirical column distribution by

\[ \bar p=\frac1T\sum_{t=1}^T p_t, \qquad \bar q=\frac1T\sum_{t=1}^T e_{j_t}. \]

For example, if a column was chosen on 30% of the rounds, \(\bar q\) assigns it probability \(0.3\). These are legitimate distributions even though the individual rounds were dependent.

For every fixed column \(j\), linearity and the best-response choice imply

\[ \bar p^{\mathsf T}Ae_j =\frac1T\sum_t p_t^{\mathsf T}Ae_j \le\frac1T\sum_t p_t^{\mathsf T}Ae_{j_t}. \]

Take the maximum over \(j\), then apply the regret inequality divided by \(T\):

\[ \max_j\bar p^{\mathsf T}Ae_j \le \min_i e_i^{\mathsf T}A\bar q+\frac{B_T}{T}. \]

This is the key step. The averaged learner works almost as well against its worst column as the best fixed row works against the averaged opponent. We do not assume that the strategies on a single round are close to optimal.

Close the gap

Since \(U\) is the minimum over all row distributions, and \(L\) is the maximum over all column distributions, the last inequality gives

\[ U\le\max_j\bar p^{\mathsf T}Ae_j \le\min_i e_i^{\mathsf T}A\bar q+\frac{B_T}{T} \le L+\sqrt{\frac{\ln N}{2T}}. \]

This holds for every positive integer \(T\), using the corresponding tuned run. Letting \(T\) grow gives \(U\le L\). Together with the easy inequality, this proves \(U=L\).

Why optimal strategies exist

We also need to know that a player can attain its optimal value, rather than only get arbitrarily close. The useful fact is that probability vectors form a compact set: every sequence of them has a subsequence converging to another probability vector.

Why compactness applies here

Every coordinate lies in \([0,1]\). Use the fact that a bounded real sequence has a convergent subsequence to make the first coordinate converge. From that subsequence, choose another on which the second coordinate converges, and continue through the finitely many coordinates. They now all converge along one subsequence. The limiting coordinates are nonnegative and still sum to 1, so the limit is a valid probability vector.

Take row distributions whose worst-case losses approach \(U\), and choose a convergent subsequence with limit \(p^*\). Against each column, expected loss is a finite weighted sum, so it converges to the loss of \(p^*\). There are only finitely many columns, so their maximum converges too. Therefore \(p^*\) has worst-case loss exactly \(U\). The same argument, using the minimum over finitely many rows, gives a column distribution attaining \(L\).

Finally, the restriction to losses in \([0,1]\) costs no generality. For a finite real matrix, subtract its smallest entry and divide by the difference between its largest and smallest entries. This positive affine change preserves optimal strategies and transforms both values in the same way. If all entries are equal, the theorem is immediate.

What the proof gives quantitatively

After \(T\) rounds, the gap between the displayed upper and lower guarantees is at most \(\sqrt{\ln N/(2T)}\). Thus \(T\ge\ln N/(2\varepsilon^2)\) suffices for gap at most \(\varepsilon\). This is useful when losses and best responses can be computed efficiently. The theorem by itself does not promise an efficient algorithm when the strategy sets are enormous.

A worked minimax example

Here is the repeated-play construction with actual numbers. Use the loss matrix

\[ A=\begin{pmatrix}0&1\\[2pt]1/2&0\end{pmatrix}. \]

Row 1 is safe against column 1 but costly against column 2. Row 2 has the opposite weakness. Start with weights \((1,1)\), and use \(\eta=2\ln2\) to keep the arithmetic simple: a loss of 1 quarters a weight, and a loss of \(1/2\) halves it. This illustrative rate is fixed; the vanishing-gap proof above uses a horizon-tuned rate.

On round 1, the column player chooses column 2 because it gives the larger expected loss. The loss vector is \((1,0)\), so row 1’s weight falls to \(1/4\). Normalizing gives the next distribution \((1/5,4/5)\). Now column 1 is the stronger attack, and its loss vector \((0,1/2)\) halves row 2’s weight.

After three rounds, average the distributions used before each update. Column 1 was chosen twice and column 2 once, so

\[ \bar p=\frac13\left[ (1/2,1/2)+(1/5,4/5)+(1/3,2/3) \right] =\left(\frac{31}{90},\frac{59}{90}\right), \qquad \bar q=\left(\frac23,\frac13\right). \]

The averaged row strategy loses \(59/180\) against column 1 and \(31/90\) against column 2. Its worst-case loss is therefore \(31/90\). Against the averaged column strategy, either pure row loses exactly \(1/3\). These distributions certify

\[ \frac13\le L\le U\le\frac{31}{90}. \]

The upper and lower guarantees differ by only \(1/90\). By comparison, the initial uniform row strategy had worst-case loss \(1/2\). Averaging has produced a much stronger guarantee in this example.

Notice that the weights after round 3 are equal again: the next distribution returns to \((1/2,1/2)\). Individual iterates can cycle. The proof controls the averaged distributions, and it bounds their gap for every finite game when the rate is tuned to the horizon. This short calculation illustrates the construction; it is not a substitute for that general proof.

Algorithms as strategies

We now turn the game into a question about computation. A randomized algorithm must succeed on every input, although its error is measured over its internal randomness. To prove it needs substantial resources, we would like to choose a distribution of inputs on which every small deterministic algorithm struggles.

We will measure resources in the query model. An algorithm receives access to an unknown input \(x\in\{0,1\}^n\). It may query an index \(i\) and learn \(x_i\). Its next query can depend on the answers already received. It eventually outputs a bit. Internal computation is free in this model; only input queries are charged.

A deterministic algorithm is represented by a decision tree. An internal node names an input bit, its two outgoing edges correspond to the possible answers, and each leaf gives the output. Depth is the maximum number of queries on a root-to-leaf path. Repeating a query cannot help, so such repetitions can be removed.

For a fixed budget \(k\), let \(\mathcal D_k\) be the finite set of deterministic trees of depth at most \(k\). A randomized algorithm with that budget can be viewed as a distribution \(\rho\) over \(\mathcal D_k\): fix all of its random bits, and the remaining behavior is deterministic. Here the budget bounds the queries on every input and every execution, rather than just the expected number.

The error convention from 455

As in the BPTIME/BPP definitions in Probabilistic Time Complexity 1, Section 4, we require error at most \(1/3\) on each input. Equivalently, for every fixed input the algorithm must succeed with probability at least \(2/3\), measured over its internal random choices. We retain that error convention while measuring input queries.

The constant \(1/3\) is conventional. The error-reduction lecture explains how independent repetitions and majority vote reduce a fixed error \(0<\varepsilon<1/2\) to any smaller positive constant. Changing to another fixed threshold in that range changes bounded-error query complexity by at most a constant factor. In the OR proof below, the factor \(1/3\) in the query lower bound comes from our particular hard-distribution calculation.

Yao’s principle

Let \(f:\{0,1\}^n\to\{0,1\}\) be the function to compute. Form a game with one row per tree \(D\in\mathcal D_k\), one column per input, and error as the loss:

\[ A_{D,x}=\mathbf 1[D(x)\ne f(x)]. \]

The symbol \(\mathbf 1[\cdot]\) is 1 when the condition holds and 0 otherwise. The row player is the algorithm designer; the column player chooses the input. Minimax gives the following identity.

Yao’s principle, fixed-budget error form

For a finite input set and query budget \(k\),

\[ \begin{aligned} & \min_{\rho\in\Delta(\mathcal D_k)} \max_{x\in\{0,1\}^n} \Pr_{D\sim\rho}[D(x)\ne f(x)]\\[6pt] &\quad= \max_{\mu\in\Delta(\{0,1\}^n)} \min_{D\in\mathcal D_k} \Pr_{x\sim\mu}[D(x)\ne f(x)]. \end{aligned} \]

Here \(\Delta(S)\) means the probability distributions on the finite set \(S\). On the left, randomization is over algorithms and the input is worst case. On the right, the input comes from a chosen distribution and the algorithm is deterministic.

Proof. In the error matrix, mixing rows according to \(\rho\) gives exactly the randomized error on each input. Mixing columns according to \(\mu\) gives exactly the average error of each deterministic tree. Substituting these meanings into finite minimax gives the identity. The inner minimization on the right can use a pure row because a mixture of error rates cannot improve on the smallest one.

The identity says more than “some input is hard.” There is a single input distribution under which even the best budget-\(k\) deterministic tree has average error equal to the best randomized algorithm’s worst-case error.

See Cornell, Section 6.3, and Blais’s notes on the minimax principle. We use the fixed-query-budget formulation, so no conversion between expected and worst-case running time is involved.

The direction needed for a lower bound

In applications, finding the optimal distribution is unnecessary. Choose any input distribution \(\mu\). If every tree in \(\mathcal D_k\) has average error strictly greater than \(1/3\), then no randomized algorithm with budget \(k\) can have error at most \(1/3\) on every input.

We can prove this direction by averaging alone. For any distribution \(\rho\) over the deterministic trees,

\[ \begin{aligned} \max_x\Pr_{D\sim\rho}[D(x)\ne f(x)] &\ge \mathbb E_{x\sim\mu}\mathbb E_{D\sim\rho} [\mathbf 1[D(x)\ne f(x)]]\\ &=\mathbb E_{D\sim\rho}\Pr_{x\sim\mu}[D(x)\ne f(x)]\\ &\ge\min_{D\in\mathcal D_k}\Pr_{x\sim\mu}[D(x)\ne f(x)]. \end{aligned} \]

The exchange of expectations is just reordering a finite sum, with \(D\) and \(x\) drawn independently. The lower-bound method is this easy inequality. The full minimax theorem supplies the converse as well, proving that the best hard distribution exactly characterizes optimal worst-case randomized error.

There may be far too many trees to list efficiently. This argument establishes a mathematical relationship between resource-bounded algorithms and input distributions; it does not provide an efficient search over all algorithms.

A randomized lower bound for OR

Consider

\[ \operatorname{OR}_n(x)=x_1\lor x_2\lor\cdots\lor x_n. \]

Finding a 1 immediately certifies the answer. The difficult case is distinguishing the all-zero string from a string whose only 1 is hidden at an unqueried position. This suggests the hard distribution

\[ \mu(0^n)=\frac12,\qquad \mu(e_i)=\frac1{2n}\quad(1\le i\le n), \]

where \(e_i\) now denotes the input string with a single 1 in position \(i\). Half the probability is on the all-zero input; the other half is spread uniformly over the \(n\) singleton inputs.

Randomized query complexity of OR

Let \(R_{1/3}(\operatorname{OR}_n)\) be the smallest worst-case query budget of a randomized algorithm whose error is at most \(1/3\) on every input. Then

\[ \frac n3\le R_{1/3}(\operatorname{OR}_n)\le n, \qquad\text{so}\qquad R_{1/3}(\operatorname{OR}_n)=\Theta(n). \]

Analyze a deterministic tree under the hard distribution

Fix any tree \(D\) of depth at most \(k\le n\). Follow the path it takes when every query returns 0. Let \(S\) be the set of indices queried along this path. Then \(|S|\le k\). There are two cases.

  1. The leaf outputs 1. The tree is wrong on \(0^n\), which has probability \(1/2\). Its average error is therefore at least \(1/2\).

  2. The leaf outputs 0. For every \(i\notin S\), the input \(e_i\) produces exactly the same answers along this path. The tree never queries the one differing bit, reaches the same leaf, and incorrectly outputs 0. These inputs have total probability \((n-|S|)/(2n)\).

In either case the tree’s average error is at least

\[ \Pr_{x\sim\mu}[D(x)\ne\operatorname{OR}_n(x)] \ge\frac{n-k}{2n}. \]

The all-zero-path argument handles adaptive algorithms: each next query is determined by the zero answers already seen, and an unqueried singleton produces all of those same answers. We never assumed the tree chose its query locations in advance.

Every deterministic budget-\(k\) tree therefore has average error greater than \(1/3\) under the same distribution. By the averaging direction of Yao’s principle, no randomized algorithm with that budget has worst-case error at most \(1/3\). This proves the lower bound. Since budgets are integers, it also implies \(R_{1/3}(\operatorname{OR}_n)\ge\lceil n/3\rceil\).

For a concrete instance, let \(n=12\) and \(k=3\). A tree that outputs 0 on the all-zero path misses at least 9 singleton inputs, causing error at least \(9/24=3/8>1/3\). A tree that outputs 1 there already has error at least \(1/2\). At \(k=4\), our bound is exactly \(1/3\), so this particular estimate does not rule out that budget. We only need a linear lower bound, not the best constant.

The upper bound is deterministic: read all \(n\) bits and output their OR. It uses at most \(n\) queries and has zero error. Combining the two sides proves \(\Theta(n)\).

The use of OR as a Yao lower-bound example is also discussed in Mittal’s query-complexity notes. The balanced distribution above gives a simple linear bound; sharper constants are not needed here.

How the pieces fit together

The link from online learning to complexity theory is the minimax proof. Expert weights give a low-regret row strategy. Playing it against best responses and averaging closes the minimax gap. Interpreting rows as bounded-query deterministic algorithms and columns as inputs gives Yao’s principle. A hard distribution then turns an average-case statement about deterministic decision trees into a worst-case lower bound for randomized computation.

The resource here is input queries. The result does not establish a general running-time lower bound for Turing machines, or separate P from BPP. It shows, in a precise model, that randomization cannot reduce OR’s cost below a linear number of input inspections.
