We now have an algorithm that does nearly as well as its best fixed choice. In this part, the choices will be rows of a game matrix. Running the algorithm against an opponent will give us a proof of minimax. We’ll then use that theorem to turn a hard distribution of inputs into a lower bound for randomized algorithms.

Games as loss matrices

A finite zero-sum game has two players with opposite goals. We’ll call them the row player and the column player. The row player wants to minimize a loss, and the column player wants to maximize it. The matrix \(A\in[0,1]^{N\times m}\) lists the loss \(A_{ij}\) when row \(i\) is played against column \(j\).

A pure strategy chooses one row or column. A mixed strategy is a probability distribution over those choices. Write

\[ \Delta_N=\{p\in\mathbb R^N:p_i\ge0,\ \sum_i p_i=1\} \]

for the possible row distributions, and similarly use \(\Delta_m\) for columns. If the players independently sample from \(p\) and \(q\), their expected loss is

\[ p^{\mathsf T}Aq=\sum_{i=1}^N\sum_{j=1}^m p_iq_j A_{ij}. \]

The superscript \(\mathsf T\) means transpose. The matrix product is just a compact way to write the expected loss. We’ll also use \(e_i\) for the distribution that always chooses one strategy. For example, \(p^{\mathsf T}Ae_j\) is the expected loss against column \(j\).

A game where randomization matters

Consider the loss matrix

\[ A=\begin{pmatrix}0&1\\1&0\end{pmatrix}. \]

If the row player commits to either pure row, the column player can choose a column giving loss 1. If the row player instead uses \(p=(1/2,1/2)\), either column gives expected loss \(1/2\). Conversely, the uniform column distribution makes every row incur loss \(1/2\). These two observations establish the value \(1/2\).

As in the prediction problem, the opponent can know our distribution, but it cannot see the row we sampled before choosing its column. Otherwise it could always pick a column that makes that particular row lose.

The minimax theorem

Suppose the row player has to announce its distribution first. It wants the distribution with the smallest loss against the worst possible column. We’ll call the resulting number the upper value:

\[ U=\min_{p\in\Delta_N}\max_{q\in\Delta_m}p^{\mathsf T}Aq =\min_{p\in\Delta_N}\max_j p^{\mathsf T}Ae_j. \]

For a fixed row distribution, mixing columns just averages their losses. That average can’t beat the largest column loss, so choosing a best pure column is enough. This explains the second equality.

Now reverse the order. The column player announces a distribution, and the row player gets to choose its best response to it. The column player wants to make even that best response costly. This gives the lower value:

\[ L=\max_{q\in\Delta_m}\min_{p\in\Delta_N}p^{\mathsf T}Aq =\max_{q\in\Delta_m}\min_i e_i^{\mathsf T}Aq. \]

A pure row is enough for the inner minimum, for the same averaging reason. The order of commitment really can matter: if we only allow pure strategies in the example above, the min–max is 1 and the max–min is 0. Minimax says that allowing distributions removes this gap.

Finite minimax theorem

For every finite loss matrix \(A\), allowing mixed strategies gives

\[ \min_{p\in\Delta_N}\max_{q\in\Delta_m}p^{\mathsf T}Aq = \max_{q\in\Delta_m}\min_{p\in\Delta_N}p^{\mathsf T}Aq. \]

The common number is the value of the game. Both players have distributions attaining their respective optima.

Each player therefore has a distribution that guarantees its side of the game value, no matter what the other player does. Our proof will use the regret bound from Part 1.

This proof follows the online-learning route in Cornell’s multiplicative-weights notes, Section 6.

Proof from the regret bound

We’ll let the learner keep adjusting its row distribution while the column player chooses a best response on every round. If the two game values had a fixed positive gap, the learner would eventually lose linearly more than some fixed row. The regret bound prevents this. We’ll then average the play to get one distribution for each player.

The easy inequality

For any distributions \(p,q\), averaging the row losses and then the column losses gives

\[ \min_i e_i^{\mathsf T}Aq \le p^{\mathsf T}Aq \le \max_j p^{\mathsf T}Ae_j. \]

For every fixed \(p\), the left side is therefore at most the right side for all \(q\). Maximize the left side over \(q\), then minimize the right side over \(p\). This proves \(L\le U\). This inequality does not need an online-learning algorithm.

Play the game repeatedly

For the reverse inequality, treat each row as an expert. Fix a number of rounds \(T\) and run exponential weights on the \(N\) rows, using the learning rate tuned to that horizon. Once the learner chooses \(p_t\), let the column player respond with

\[ j_t\in\operatorname*{arg\,max}_{1\le j\le m}p_t^{\mathsf T}Ae_j. \]

Break ties using any fixed rule. Give the learner the losses \(\ell_{i,t}=A_{i,j_t}\). Every entry is in \([0,1]\), so we can apply the regret theorem. Choosing a best response after seeing \(p_t\) is allowed: the proof in Part 1 covered losses chosen this way.

The learner’s round loss is \(p_t^{\mathsf T}Ae_{j_t}\). Its best fixed expert is the best row against the whole sequence of selected columns. Hence

\[ \sum_{t=1}^T p_t^{\mathsf T}Ae_{j_t} \le \min_i\sum_{t=1}^T A_{i,j_t}+B_T, \qquad B_T=\sqrt{\frac{T\ln N}{2}}. \]

The game with one row is immediate, so we can assume \(N\ge2\) when using this bound.

Average the strategies

Define the average row distribution and the empirical column distribution by

\[ \bar p=\frac1T\sum_{t=1}^T p_t, \qquad \bar q=\frac1T\sum_{t=1}^T e_{j_t}. \]

If the opponent chose a column on 30% of the rounds, then \(\bar q\) gives that column probability \(0.3\). Both averages are probability distributions. We don’t need the choices on different rounds to be independent.

For every fixed column \(j\), linearity and the best-response choice imply

\[ \bar p^{\mathsf T}Ae_j =\frac1T\sum_t p_t^{\mathsf T}Ae_j \le\frac1T\sum_t p_t^{\mathsf T}Ae_{j_t}. \]

Take the maximum over \(j\), then apply the regret inequality divided by \(T\):

\[ \max_j\bar p^{\mathsf T}Ae_j \le \min_i e_i^{\mathsf T}A\bar q+\frac{B_T}{T}. \]

This is why we took averages. We have a row distribution whose worst-case loss is close to the loss of the best fixed row against our column distribution. The strategies on individual rounds can move around; the guarantee we need is about their averages.

Close the gap

Since \(U\) is the minimum over all row distributions, and \(L\) is the maximum over all column distributions, the last inequality gives

\[ U\le\max_j\bar p^{\mathsf T}Ae_j \le\min_i e_i^{\mathsf T}A\bar q+\frac{B_T}{T} \le L+\sqrt{\frac{\ln N}{2T}}. \]

We can do this for every positive integer \(T\), choosing the tuned rate for each run. As \(T\) grows, the error term goes to zero, giving \(U\le L\). Combined with the inequality in the other direction, this proves \(U=L\).

Why optimal strategies exist

One detail remains: we want distributions that actually reach the optimal values, rather than only get arbitrarily close. Probability vectors form a compact set. For our purposes, this means that any sequence of probability vectors has a subsequence converging to another probability vector.

Why compactness applies here

Every coordinate lies in \([0,1]\). Use the fact that a bounded real sequence has a convergent subsequence to make the first coordinate converge. From that subsequence, choose another on which the second coordinate converges, and continue through the finitely many coordinates. They now all converge along one subsequence. The limiting coordinates are nonnegative and still sum to 1, so the limit is a valid probability vector.

Take row distributions whose worst-case losses approach \(U\), and choose a convergent subsequence with limit \(p^*\). Against each column, expected loss is a finite weighted sum, so it converges to the loss of \(p^*\). There are only finitely many columns, so their maximum converges too. Therefore \(p^*\) has worst-case loss exactly \(U\). The same argument, using the minimum over finitely many rows, gives a column distribution attaining \(L\).

We can also handle entries outside \([0,1]\). Subtract the smallest matrix entry, then divide by the difference between the largest and smallest entries. This rescales every loss in the same way, so optimal strategies stay the same and both game values transform together. If all entries are equal, there is nothing to prove.

What the proof gives quantitatively

The proof also tells us how many rounds we need. After \(T\) rounds, the gap is at most \(\sqrt{\ln N/(2T)}\). Taking \(T\ge\ln N/(2\varepsilon^2)\) makes it at most \(\varepsilon\). Whether this gives an efficient algorithm depends on how hard it is to compute the losses and best responses, and how many strategies we have to maintain.

A worked minimax example

Let’s see what these averages look like in a small game. Take

\[ A=\begin{pmatrix}0&1\\[2pt]1/2&0\end{pmatrix}. \]

Row 1 does well against column 1 but badly against column 2. Row 2 has the opposite weakness. Start with weights \((1,1)\) and use \(\eta=2\ln2\) so the arithmetic stays simple: loss 1 quarters a weight, while loss \(1/2\) halves it. We’re choosing this fixed rate for the example; the proof above uses the rate tuned to the horizon.

On round 1, the column player chooses column 2 because it gives the larger expected loss. The loss vector is \((1,0)\), so row 1’s weight falls to \(1/4\). Normalizing gives the next distribution \((1/5,4/5)\). Now column 1 is the stronger attack, and its loss vector \((0,1/2)\) halves row 2’s weight.

After three rounds, average the distributions used before each update. Column 1 was chosen twice and column 2 once, so

\[ \bar p=\frac13\left[ (1/2,1/2)+(1/5,4/5)+(1/3,2/3) \right] =\left(\frac{31}{90},\frac{59}{90}\right), \qquad \bar q=\left(\frac23,\frac13\right). \]

The averaged row strategy loses \(59/180\) against column 1 and \(31/90\) against column 2. Its worst-case loss is therefore \(31/90\). Against the averaged column strategy, either pure row loses exactly \(1/3\). These distributions certify

\[ \frac13\le L\le U\le\frac{31}{90}. \]

The two guarantees are only \(1/90\) apart. The starting uniform row distribution had worst-case loss \(1/2\), so averaging these three rounds already gives a much better guarantee in this game.

After round 3, the weights are equal again, so the next distribution returns to \((1/2,1/2)\). With this fixed rate, the cycle can repeat. We don’t need every individual distribution to settle down: the proof uses averaged distributions and a horizon-tuned rate to make their guarantee gap go to zero.

Algorithms as strategies

To connect this to complexity theory, we’ll make algorithms the row strategies and inputs the column strategies. A randomized algorithm has to keep its error small on every input. A lower-bound proof can instead look for one distribution of inputs that makes every small deterministic algorithm do badly.

We will measure resources in the query model. An algorithm receives access to an unknown input \(x\in\{0,1\}^n\). It may query an index \(i\) and learn \(x_i\). Its next query can depend on the answers already received. It eventually outputs a bit. Internal computation is free in this model; only input queries are charged.

A deterministic algorithm is represented by a decision tree. An internal node names an input bit, its two outgoing edges correspond to the possible answers, and each leaf gives the output. Depth is the maximum number of queries on a root-to-leaf path. Repeating a query cannot help, so such repetitions can be removed.

Fix a query budget \(k\), and let \(\mathcal D_k\) be all deterministic trees of depth at most \(k\). This is a finite set. Once we fix a randomized algorithm’s random bits, its behavior is one of these trees. So we can describe the algorithm as a distribution \(\rho\) over \(\mathcal D_k\). The budget is a bound on every execution on every input, rather than an expected query count.

The error convention from 455

We’ll use the same error convention as the BPTIME/BPP definitions in Probabilistic Time Complexity 1, Section 4: error at most \(1/3\) on each input. In other words, fix any input, and the algorithm must answer correctly with probability at least \(2/3\) over its own random choices. Here we’re counting queries as the resource.

There’s nothing special about \(1/3\). From the error-reduction lecture, independent repetitions and majority vote reduce any fixed error \(0<\varepsilon<1/2\) to a smaller positive constant. A different fixed threshold in this range changes bounded-error query complexity by at most a constant factor. The separate factor of \(1/3\) in our OR query lower bound will come from the calculation with the hard distribution.

Yao’s principle

Let \(f:\{0,1\}^n\to\{0,1\}\) be the function to compute. Form a game with one row per tree \(D\in\mathcal D_k\), one column per input, and error as the loss:

\[ A_{D,x}=\mathbf 1[D(x)\ne f(x)]. \]

Here \(\mathbf 1[\cdot]\) is 1 when the condition is true and 0 otherwise. Each matrix entry tells us whether a particular algorithm is wrong on a particular input. The row player chooses the algorithm, and the column player chooses the input. Applying minimax gives:

Yao’s principle, fixed-budget error form

For a finite input set and query budget \(k\),

\[ \begin{aligned} & \min_{\rho\in\Delta(\mathcal D_k)} \max_{x\in\{0,1\}^n} \Pr_{D\sim\rho}[D(x)\ne f(x)]\\[6pt] &\quad= \max_{\mu\in\Delta(\{0,1\}^n)} \min_{D\in\mathcal D_k} \Pr_{x\sim\mu}[D(x)\ne f(x)]. \end{aligned} \]

As before, \(\Delta(S)\) is the set of probability distributions on the finite set \(S\). On the left, we choose a randomized algorithm and face its worst input. On the right, we choose a hard input distribution and allow the best deterministic algorithm for that distribution.

Proof. A distribution \(\rho\) over the rows is exactly a randomized algorithm, and its loss on a column is its error probability on that input. A distribution \(\mu\) over columns gives the average error of each deterministic tree. These are the two sides of the minimax theorem for this matrix. For the inner minimum on the right, a mixture of trees cannot improve on the best single tree.

The useful point is that we get one input distribution for all budget-\(k\) trees at once. Even a tree chosen specifically for that distribution has average error at least the optimal randomized algorithm’s worst-case error.

See Cornell, Section 6.3, and Blais’s notes on the minimax principle. This version fixes a query budget and compares error probabilities, so we don’t have to convert between expected and worst-case running time.

The direction needed for a lower bound

For a lower bound, we don’t have to find the best possible hard distribution. We can choose any \(\mu\) that is useful. If every tree in \(\mathcal D_k\) has average error greater than \(1/3\) under it, then no randomized algorithm with budget \(k\) can have error at most \(1/3\) on every input.

We can prove this direction by averaging alone. For any distribution \(\rho\) over the deterministic trees,

\[ \begin{aligned} \max_x\Pr_{D\sim\rho}[D(x)\ne f(x)] &\ge \mathbb E_{x\sim\mu}\mathbb E_{D\sim\rho} [\mathbf 1[D(x)\ne f(x)]]\\ &=\mathbb E_{D\sim\rho}\Pr_{x\sim\mu}[D(x)\ne f(x)]\\ &\ge\min_{D\in\mathcal D_k}\Pr_{x\sim\mu}[D(x)\ne f(x)]. \end{aligned} \]

We can swap the expectations because they are finite sums, with \(D\) and \(x\) drawn independently. This inequality alone is enough to prove a randomized lower bound. The full minimax theorem adds the other direction: the best hard distribution exactly matches the optimal worst-case randomized error.

The set of trees can be enormous. The matrix lets us reason about all of them at once; computing optimal strategies by listing every tree could take far too long.

A randomized lower bound for OR

Consider

\[ \operatorname{OR}_n(x)=x_1\lor x_2\lor\cdots\lor x_n. \]

Finding a 1 is enough to answer OR. If all the bits we have read are 0, though, the input could still have a single 1 somewhere we haven’t looked. This suggests putting probability on the all-zero string and on strings with exactly one 1:

\[ \mu(0^n)=\frac12,\qquad \mu(e_i)=\frac1{2n}\quad(1\le i\le n), \]

Here \(e_i\) means the input string with its only 1 at position \(i\). The all-zero input gets half the probability, and the \(n\) singleton inputs share the other half equally.

Randomized query complexity of OR

Let \(R_{1/3}(\operatorname{OR}_n)\) be the smallest worst-case query budget of a randomized algorithm whose error is at most \(1/3\) on every input. Then

\[ \frac n3\le R_{1/3}(\operatorname{OR}_n)\le n, \qquad\text{so}\qquad R_{1/3}(\operatorname{OR}_n)=\Theta(n). \]

Analyze a deterministic tree under the hard distribution

Take any deterministic tree \(D\) with depth at most \(k\le n\), and run it on the all-zero input. Let \(S\) be the set of indices it queries along that path. We have \(|S|\le k\). Now look at the output at the end of the path:

  1. The leaf outputs 1. The tree is wrong on \(0^n\), which has probability \(1/2\). Its average error is therefore at least \(1/2\).

  2. The leaf outputs 0. For every \(i\notin S\), the input \(e_i\) produces exactly the same answers along this path. The tree never queries the one differing bit, reaches the same leaf, and incorrectly outputs 0. These inputs have total probability \((n-|S|)/(2n)\).

In either case the tree’s average error is at least

\[ \Pr_{x\sim\mu}[D(x)\ne\operatorname{OR}_n(x)] \ge\frac{n-k}{2n}. \]

This still works if the queries are adaptive. On the all-zero path, each next query is determined by the zero answers so far. A singleton outside the queried set gives those same answers and therefore follows exactly the same path.

For example, take \(n=12\) and \(k=3\). If the tree outputs 0 on the all-zero path, it misses at least 9 singleton inputs. That gives error at least \(9/24=3/8>1/3\). If it outputs 1 there, its error is at least \(1/2\). At \(k=4\), our estimate is exactly \(1/3\), so it no longer rules out that budget. We only need a linear bound here, so this constant is enough.

The upper bound is deterministic: read all \(n\) bits and output their OR. It uses at most \(n\) queries and has zero error. Combining the two sides proves \(\Theta(n)\).

The use of OR as a Yao lower-bound example is also discussed in Mittal’s query-complexity notes. The balanced distribution above gives a simple linear bound; sharper constants are not needed here.

What we proved

The same weight-update algorithm has now done two jobs. First, its regret guarantee proved minimax. Then, by treating algorithms and inputs as strategies, minimax gave us Yao’s principle. For OR, a hard input distribution let us turn a statement about deterministic trees’ average error into a worst-case lower bound for randomized algorithms.

This is a lower bound in the query model: even with randomization, OR needs a linear number of input queries. It gives a concrete limitation on randomized algorithms without separating P from BPP.
