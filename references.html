References

These are the main references for the project, with a short note on what each one covers.

  1. Prediction, Learning, and Games

    Nicolò Cesa-Bianchi and Gábor Lugosi. Cambridge University Press, 2006.

    Chapters 2 and 4 develop prediction with expert advice and randomized prediction. Theorem 2.2 gives the exponential-weights bound used in Part 1, with the constant 1/8 in the learning-rate term.

  2. The Multiplicative Weights Update Method: A Meta-Algorithm and Applications

    Sanjeev Arora, Elad Hazan, and Satyen Kale. Theory of Computing, 8, 2012, pp. 121–164.

    A survey of multiplicative weights and its applications. Useful for seeing other places where the same update rule appears.

  3. Cornell CS 6820 notes on multiplicative weights

    CS 6820, Cornell University, Fall 2024.

    The proof in Part 2 follows Section 6, which derives minimax from online learning. Section 6.3 then uses the theorem to derive Yao’s lemma.

  4. Minimax Principle

    Eric Blais. CS 860, University of Waterloo, Winter 2025.

    Helpful for understanding the difference between the full minimax equality and the averaging argument used for lower bounds. This project uses a fixed query budget and compares error probabilities.

  5. Yao’s min-max for randomized query complexity

    Rajat Mittal. IIT Kanpur course notes.

    Introduces the query model and uses OR as a randomized lower-bound example. The proof here uses a balanced mixture of the all-zero input and singleton inputs, sufficient for a linear lower bound.
