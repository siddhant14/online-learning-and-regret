Suppose several prediction rules give us advice before each outcome. We don’t know which rule will do best, so we’ll track their losses and adjust how much we rely on each one. Our goal is to finish with a total loss close to that of the best rule we could have chosen in hindsight.

The prediction game

An expert is just a prediction rule. It might be a model, a person, or something as simple as “predict the same outcome as last time.” The name doesn’t mean the rule is good: our analysis allows bad experts too.

For a binary prediction problem, the outcome and each expert’s prediction belong to \(\{0,1\}\). On each round:

  1. The learner receives the experts’ predictions.
  2. The learner chooses its prediction before seeing the outcome.
  3. The outcome is revealed, so the learner can determine which experts were wrong.
  4. The learner updates the influence given to each expert.

We call this a full-information problem because, once the outcome is revealed, we can work out every expert’s loss. We get this feedback even for experts whose advice we didn’t follow.

For the proof, we’ll allow slightly more general losses. There are \(N\ge2\) experts and \(T\ge1\) rounds. Expert \(i\) gets loss \(\ell_{i,t}\in[0,1]\) on round \(t\). A binary prediction has loss 1 when it is wrong and 0 when it is right. Fractional losses will be useful when we apply the same algorithm to a matrix game in Part 2.

What regret measures

If the outcomes can be chosen adversarially, we shouldn’t expect the learner to get everything right. A more useful goal is to do about as well as the best available expert. If all the experts make lots of mistakes, our guarantee should account for that.

Cumulative loss and regret

The cumulative loss of expert \(i\) is

\[ L_{i,T}=\sum_{t=1}^{T}\ell_{i,t}. \]

If the learner uses a probability vector \(p_t=(p_{1,t},\ldots,p_{N,t})\), define its mixture loss by

\[ \widehat\ell_t=\sum_{i=1}^{N}p_{i,t}\ell_{i,t}, \qquad \widehat L_T=\sum_{t=1}^{T}\widehat\ell_t. \]

Its regret against the best fixed expert is

\[ R_T=\widehat L_T-\min_{1\le i\le N}L_{i,T}. \]

The word “fixed” is important. After all \(T\) rounds, we pick one expert and count that expert’s loss over the whole sequence. We don’t get to switch experts after seeing each outcome. If the expert totals are 10, 14, and 9, the benchmark is 9. A learner total of 11 then gives regret 2.

Regret can be negative for some prediction rules: a learner might do better than every fixed expert. For the particular algorithm we’ll analyze here, exponential weights with equal starting weights and a fixed learning rate, cumulative mixture regret is nonnegative.

Small regret doesn’t necessarily mean few mistakes. A learner with loss 102 against a best expert with loss 100 has regret only 2. The comparison is good, even though the learner’s total loss is large.

To make an actual randomized prediction, sample expert \(i\) with probability \(p_{i,t}\) and follow its advice. Then \(\widehat\ell_t\) is the conditional expected loss of that prediction. We need the losses to be fixed without seeing which expert was sampled. The opponent can know our probability vector, but it cannot see our random choice before picking the outcome.

The weight update

Give every expert weight 1 to start. Before each prediction, divide by the total weight to get a probability distribution. After we see the losses, reduce the weights of experts that did badly. Exponential weights uses the following update:

Exponential weights

Choose a fixed learning rate \(\eta>0\). Initialize \(w_{i,1}=1\). On each round \(t\), use

\[ W_t=\sum_{j=1}^{N}w_{j,t}, \qquad p_{i,t}=\frac{w_{i,t}}{W_t}. \]

After observing all losses, update

\[ w_{i,t+1}=w_{i,t}e^{-\eta\ell_{i,t}}. \]

For binary losses, a correct expert keeps its weight and a mistaken expert gets multiplied by \(\beta=e^{-\eta}\). A larger learning rate gives a bigger penalty for a mistake, so the distribution reacts faster. A smaller rate makes it change more gradually.

Expanding the updates over the previous rounds gives

\[ w_{i,t}=e^{-\eta L_{i,t-1}}. \]

So the weight used on round \(t\) is determined entirely by losses from earlier rounds. We can compute it before the next outcome is known.

How Weighted Majority fits

Deterministic Weighted Majority uses these weights to take a vote. It predicts the label with at least half the total weight and uses a fixed rule to break ties. Randomized weighted prediction samples an expert instead. The weight update is the same, but the prediction rule changes the guarantee we can prove.

To see why the prediction rule matters, imagine an opponent that always chooses the opposite of a deterministic learner’s prediction. The learner is wrong on every round. Yet one of the always-0 and always-1 experts makes at most half as many mistakes. With randomization, we can avoid giving the opponent this advantage, provided it cannot see the current random choice.

We’ll prove the bound for exponential weights and its mixture loss. You can also try deterministic voting in the simulation; the bound shown in that mode is on total mistakes.

A worked example

Let’s work through two rounds with four experts, equal starting weights, and \(\eta=\ln 2\). With this choice, a mistake halves an expert’s weight.

The first prediction uses the old probabilities \(1/4\), so its expected loss is \(3/4\). The new probabilities only affect the next round. If the next advice is \([0,1,1,1]\) and the next outcome is again 1, only A is wrong. The second-round mixture loss is therefore \(1/5\), giving a cumulative loss of \(3/4+1/5=19/20\).

B is correct on both rounds, so the best expert’s loss is 0 and the learner’s regret is \(19/20\). The fractional value comes from taking an expected loss. A single sampled run would have an integer number of mistakes.

The regret bound

Exponential-weights regret guarantee

For every sequence of full-information loss vectors in \([0,1]^N\), exponential weights with equal initial weights and fixed \(\eta>0\) satisfies

\[ \boxed{R_T\le \frac{\ln N}{\eta}+\frac{\eta T}{8}.} \]

For a known horizon \(T\), choosing \(\eta=\sqrt{8\ln N/T}\) gives

\[ R_T\le\sqrt{\frac{T\ln N}{2}}. \]

The two terms tell us how to choose the learning rate. If \(\eta\) is too small, \(\ln N/\eta\) is large. If \(\eta\) is too large, \(\eta T/8\) is large. The chosen rate balances these terms. For fixed \(N\), divide by \(T\):

\[ \frac{R_T}{T}\le\sqrt{\frac{\ln N}{2T}}\longrightarrow0. \]

This is what sublinear regret gives us: the extra loss per round, compared with the best fixed expert, goes to zero. Here we chose the learning rate using the number of rounds. If we kept one positive rate fixed forever, this bound would not give a vanishing average regret.

The bound is the exponential-weights guarantee in Cesa-Bianchi and Lugosi, Theorem 2.2, applied to mixture loss. The binary randomized-prediction interpretation uses the protocol above.

Proof using total weight

The useful quantity to track is the total weight \(W_t\). It includes the best expert’s weight, which gives us one bound. The update rule also ties the change in total weight to the learner’s loss on each round. Putting these two facts together will let us compare the learner with the best expert.

The exponential average we need

Hoeffding’s lemma

If \(X\) takes values in \([0,1]\), then for every real \(s\),

\[ \ln\mathbb E[e^{sX}] \le s\,\mathbb E[X]+\frac{s^2}{8}. \]

We need a bound on an exponential average, which is what this lemma gives us. It is related to the Hoeffding tail bound from the error-reduction lecture, though the formula we use here is different.

Proof of the lemma for a finite distribution

Write \(g(s)=\ln\sum_i p_i e^{s x_i}\), where \(0\le x_i\le1\). Then \(g(0)=0\) and \(g'(0)=\sum_i p_i x_i=\mathbb E[X]\). Differentiating twice shows that \(g''(s)\) is the variance of \(X\) under the tilted probabilities

\[ p_i(s)=\frac{p_i e^{s x_i}}{\sum_jp_j e^{s x_j}}. \]

Every distribution on \([0,1]\) has variance at most \(1/4\), since

\[ \operatorname{Var}(X) \le\mathbb E[(X-\tfrac12)^2]\le\tfrac14. \]

Taylor’s theorem, together with \(g''\le1/4\), gives \(g(s)\le g(0)+s g'(0)+s^2/8\). That proves the lemma. This is the only step that uses differentiation; the rest of the regret proof is algebra.

Lower bound: keep the best expert’s contribution

After \(T\) rounds, expert \(i\) has weight \(e^{-\eta L_{i,T}}\). The total weight is at least the weight of the best expert, so

\[ W_{T+1}\ge e^{-\eta\min_i L_{i,T}}. \]

Since \(W_1=N\), taking logarithms gives

\[ \ln\frac{W_{T+1}}{W_1} \ge-\eta\min_i L_{i,T}-\ln N. \]

Even if the other experts have almost no weight left, their weights cannot pull the total below the best expert’s contribution.

Upper bound: measure the decrease each round

The update and normalization give

\[ \frac{W_{t+1}}{W_t} =\sum_i p_{i,t}e^{-\eta\ell_{i,t}}. \]

Apply Hoeffding’s lemma to the loss of an expert sampled from \(p_t\), with \(s=-\eta\):

\[ \ln\frac{W_{t+1}}{W_t} \le-\eta\widehat\ell_t+\frac{\eta^2}{8}. \]

Now add these inequalities over all rounds. The intermediate total weights cancel inside the logarithms:

\[ \ln\frac{W_{T+1}}{W_1} \le-\eta\widehat L_T+\frac{\eta^2T}{8}. \]

Combine the two bounds

We have a lower and an upper bound on the same log ratio, so we can combine them:

\[ -\eta\min_i L_{i,T}-\ln N \le-\eta\widehat L_T+\frac{\eta^2T}{8}. \]

Rearranging and dividing by \(\eta\), which is positive, gives

\[ \widehat L_T-\min_i L_{i,T} \le\frac{\ln N}{\eta}+\frac{\eta T}{8}. \]

This proves the regret bound. We never assumed that the losses were random or independent. The opponent could even choose each loss vector after seeing the learner’s current probability vector. That is the case we’ll need in the minimax proof.

Reading the simulation

Start the expert-advice simulation in randomized/Hedge mode and use “Next round” a few times. It is easier to follow the updates one at a time before running the full sequence.

  • Weights: the bars show the normalized weights used for the next round. A mistake reduces an expert’s unnormalized weight; normalization changes everyone’s probability.
  • Learner loss: Hedge mode displays mixture loss, equal to conditional expected mistakes under the stated prediction protocol. No random expert is sampled.
  • Best expert: the comparison curve is the smallest cumulative expert loss at each prefix. Each comparison uses one fixed expert for that entire prefix.
  • Regret: subtract the best-expert total from the learner total. Regret may decrease between rounds. In this simulation’s Hedge mode, equal initial weights and a fixed learning rate keep cumulative mixture regret nonnegative. In deterministic Weighted Majority mode, regret can be negative.

Try the steady-signal preset first, then the regime switch. The second example is a reminder of what our benchmark measures: the theorem compares us with one expert for the whole run. It doesn’t promise that we’ll immediately follow a different expert when the pattern changes. Try the same sequence with a few learning rates to see how quickly the weights react.

The examples show particular runs; the proof covers every valid loss sequence. The simulation rounds the tuned learning rate to a slider value, so it may differ slightly from the exact formula. Changing any setup option resets the run, keeping the rate fixed within each experiment.
