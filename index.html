Online Learning
and Regret

From expert advice to lower bounds for randomized algorithms

Why I chose this topic

I've worked with ML models and trading signals before, so I'm interested in how learning algorithms perform when data arrives sequentially and predictions have to be made without knowing what comes next. I want to explore what guarantees we can make even when the data is unpredictable or adversarial.

I plan to use this as a starting point for studying randomized computation. The project will connect the regret guarantee for multiplicative weights to the minimax theorem, then use Yao’s principle to prove a lower bound on the number of input bits an algorithm must read.

Background

I’ll assume basic probability, expectations, asymptotic notation, and the definition of bounded-error randomized computation from 455. I’ll introduce the expert-advice framework, finite zero-sum games, and the query-complexity model as they are needed. No prior ML or game-theory course is assumed.

Proposed outline

Part 1: Online learning and regret

  1. The prediction problem

    I’ll define expert predictions, losses, and regret relative to the best fixed expert in hindsight. A short worked example will show how this comparison differs from choosing a new expert on every round.

  2. Multiplicative weights

    I’ll introduce Weighted Majority as motivation, then focus on randomized weighted prediction and its expected loss. I’ll explain the weight update and use the simulation to show the effect of the learning rate.

    Open the expert-advice simulation

  3. The regret bound and its proof

    I’ll state the exponential-weights guarantee and prove it using the total expert weight as a potential. I’ll explain the upper and lower bounds on that quantity, the choice of learning rate, and the meaning of sublinear regret.

Part 2: Minimax and randomized lower bounds

  1. Finite zero-sum games

    I’ll introduce a loss matrix and probability distributions over strategies, using a small game as an example. This will set up the distinction between choosing a randomized strategy and facing a distribution of opposing choices.

  2. Proving the minimax theorem

    This will be the centerpiece theorem. I’ll run exponential weights against best responses and show how the regret bound makes the gap between the two game values approach zero, completing a proof of minimax equality.

  3. Yao’s principle

    I’ll apply minimax to a matrix whose rows are deterministic algorithms with a fixed query budget and whose columns are inputs. This gives a precise relationship between worst-case error for randomized algorithms and average error for deterministic algorithms under a hard input distribution.

  4. A lower bound for OR

    I’ll define decision trees and measure their cost by the number of input bits queried. Using an input distribution supported on the all-zero string and strings with one 1, I’ll prove that a bounded-error randomized algorithm for OR needs linearly many queries, and give a matching asymptotic upper bound.

  • The Multiplicative Weights Update Method: A Meta-Algorithm and Applications, Sanjeev Arora, Elad Hazan, and Satyen Kale.

  • Minimax Principle, Eric Blais. Randomized and distributional complexity.
  • Yao’s min-max for randomized query complexity, Rajat Mittal. Decision trees and the randomized query complexity of OR.
